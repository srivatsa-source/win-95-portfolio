## 🎯 About This Portfolio

Welcome to an interactive portfolio experience that brings back the iconic Windows 95 interface! This project showcases **Srivatsa S**'s skills as a graphic designer and software developer through a fully functional retro-themed desktop environment.

Experience the nostalgia of Windows 95 while exploring modern web development practices, interactive features, and a personality-driven design with **Ora the Cat** as your friendly guide!

---

## ✨ Key Features

### 🪟 **Authentic Windows 95 Experience**
- **Pixel-perfect recreation** of the classic Windows 95 UI
- **MS Sans Serif** font for authentic typography
- **Windows 95 color scheme** with the iconic `#c0c0c0` silver-gray background
- **Startup sequence** with loading messages and startup sound
- **Fully functional taskbar** with Start menu, time display, and window management

### 🖱️ **Interactive Desktop**
- **Draggable desktop icons** with grid snapping
- **Double-click to open** windows (just like the real thing!)
- **Right-click context menus** for desktop and icons
- **Window management**: Minimize, maximize, close, and drag windows
- **Window resizing** with draggable handles
- **Auto-arranging icons** to keep your desktop organized

### 🐱 **Ora the Cat - Your AI Guide**
- **Interactive chatbot** with personality and knowledge about the portfolio
- **Guided tour** using Driver.js with 7 steps through the portfolio
- **Animated pixel-art cat** mascot that responds to interactions
- **Multiple cat expressions**: Normal, smiling, and pointing
- **Floating cat assistant** always available to help

### 💬 **Chatbot Features**
- **Intelligent keyword matching** to answer questions
- **Knowledge base** covering:
  - Who is Srivatsa
  - Skills and technologies
  - Project portfolio
  - Fun facts and features
- **Chat history** with timestamps
- **Typing indicator** for realistic conversation flow
- **Draggable chat window** with fullscreen mode

### 📝 **Guestbook & Visitor Counter**
- **Visitor counter** tracking all site visits
- **Interactive guestbook** for leaving messages
- **Profanity filter** to keep things friendly
- **LocalStorage persistence** - your entries are saved!
- **Timestamp tracking** for each entry
- **Vintage guestbook styling**

### 🎮 **Minesweeper Game**
- **Classic Minesweeper** gameplay with authentic Windows 95 styling
- **Three difficulty levels**:
  - Easy (9×9, 10 mines)
  - Medium (16×16, 40 mines)
  - Hard (16×30, 99 mines)
- **Mine counter** and game timer
- **Flag system** for marking suspected mines
- **Flood fill algorithm** for revealing empty cells
- **Win/lose detection** with appropriate alerts

## 🎮 How to Use

### Getting Started
1. **Wait for the startup sequence** - Enjoy the nostalgic boot screen
2. **Click "Enter Portfolio"** in the welcome dialog
3. **Follow Ora's guided tour** or explore on your own!

### Exploring the Portfolio
- **Double-click desktop icons** to open windows
- **Drag windows** by their title bars
- **Minimize/Maximize/Close** using window controls
- **Right-click** for context menus
- **Click the Start button** for the Start menu

### Interacting with Ora
- **Click the floating cat** at the bottom center to open chat
- **Ask questions** about Srivatsa, skills, or projects
- **Use quick-reply buttons** for common questions

### Playing Minesweeper
- **Left-click** to reveal cells
- **Right-click** to place flags
- **Choose difficulty** from the dropdown menu
- **Click "New Game"** to restart

### Signing the Guestbook
- **Click the guestbook icon** in the taskbar (bottom right)
- **Enter your name and message**
- **Click "Sign Guestbook"** to submit
